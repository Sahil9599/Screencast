# 📱 Mirror Cast - Mobile to PC Screen Mirroring & Recorder

Cast and Record Android phone screen to PC in **Real-Time High FPS (60 / 90 / 120 FPS)**!

---

## 🔴 Real-Time FPS Screen Recording:
- Screen mirror karte waqt **direct MP4 me record** hota hai.
- **Hardware Direct Stream**: 0% extra CPU/GPU usage on PC (Hardware MediaCodec bitstream directly disk par save hoti hai).
- **Exact High Refresh Rate**: Agar aapne 120 FPS select kiya hai, toh video exact **120 FPS MP4** me record hogi!
- **1-Click Open Folder**: `📁 Open Recordings` button se sabhi video files turant access karein.

---

## ⚡ Connection Modes:
1. 🔌 **Direct USB Cable Mode** (Ultra-Low Latency: **~15 ms**, 24 Mbps, Zero Lag)
2. 📶 **Wireless Hotspot Mode** (Convenient zero-wire casting over Wi-Fi)

---

## 🚀 How to Record Screen:

1. [start.bat](file:///C:/Users/mrxsi/.gemini/antigravity/scratch/mirror-cast/start.bat) par double-click karein.
2. Frame Rate me **60 FPS / 90 FPS / 120 FPS** select karein.
3. Checkbox tick karein: **"🔴 Record Screen (Real-Time FPS: 60/90/120)"**.
4. **"Start Mirroring"** dabayein — Screen cast bhi hogi aur simultaneously background me 120 FPS video save hoti rahegi!
5. Stop dabate hi MP4 file `recordings/` folder me save ho jayegi.
